# Document / Writing Domain

Preserve user intent while improving clarity, structure, accuracy, audience fit, and usefulness.

Require a complete final version when the user needs sendable/publishable text; do not return only fragments or edit notes unless requested.

Specify audience, tone, language, format, and length only to the degree they materially affect quality.

For factual/legal/technical/medical/financial/regulatory claims, add verification or qualification requirements appropriate to risk.
