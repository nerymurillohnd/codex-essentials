# Changelog

Notable changes to this plugin are documented here for its users.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and plugin versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.1] - 2026-10-09

### Changed

- Prefer LSP Intelligence for semantic queries when available and keep the packaged helper as an explicitly limited fallback.

## [0.1.0] - 2026-10-05

### Added

- Version-aware workflows for Svelte components, SvelteKit routes and migrations, Svelte CLI, Astro islands, and Tailwind CSS integration.
- Official Svelte MCP documentation lookup and autofixer with a local CLI fallback.
- Separate component editor and read-only auditor skills.
- A local Svelte language-server client for semantic navigation and diagnostics, with explicit fallbacks when the server is absent.
- Original visual assets and installation and verification guidance, with test fixtures maintained in the repository outside the release ZIP.
