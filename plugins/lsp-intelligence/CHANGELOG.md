## [0.1.0] - 2026-10-09

### Added

- Global stdio MCP adapter for 31 pinned mcpls tools and runtime status.
- Explicit workspace routing, bounded backend isolation, unsigned-format validation, and preview-only edits.
- User-scoped verified bridge installation, profile setup, updates and rollback.
- Setup, semantic navigation, and diagnostic verification skills.
- TypeScript/JavaScript, Svelte, Astro, Python and Bash profiles.

This is a locally prepared version; publication and platform acceptance are reported separately.
