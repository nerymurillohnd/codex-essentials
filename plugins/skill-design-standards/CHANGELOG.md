## [Unreleased]

### Added

- Package the Skill Design Standards workflow and six focused references as a
  self-contained community plugin with automatic skill discovery and no hooks,
  bundled executables, MCP servers, apps, or credential requirements.
- Document portable skill format, Codex metadata, script interfaces, description
  optimization, output-quality evaluation, and evidence-based validation.
- Add installation, verification, standalone-skill migration, and recovery guidance.

### Changed

- Make host-provided creator tools optional and remove reliance on a machine-local
  creator reference or validator so the distributed plugin works independently.
