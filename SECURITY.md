# Security policy

Do not disclose a suspected vulnerability in a public issue. Report it privately by email to [nerymurillohnd@gmail.com](mailto:nerymurillohnd@gmail.com). GitHub's private vulnerability reporting is an additional route only if the maintainers enable it; check the repository's Security tab before using that route.

Include a concise description, affected plugin and version, reproduction steps, and potential impact. Do not include real secrets or personal data in reports. The repository has no published releases yet, so there are no supported release versions to list.
