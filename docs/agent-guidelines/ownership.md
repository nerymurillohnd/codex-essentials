# Ownership and Context Guidelines

The repository owner is Nery Samuel Murillo (`nerymurillohnd`) and the project is MIT-licensed. This repository is intended for community distribution of Codex plugins and data.

Personal operating context and Forestal MT business context are intentionally not duplicated in this public contributor guide. Keep that material in the authorized global configuration or a private context skill, and reference it only when the task explicitly requires it. Do not infer private business requirements from this repository alone.
