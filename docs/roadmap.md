# Codex Essentials Roadmap

Codex Essentials is a public marketplace for distributable Codex plugins. This
roadmap is intentionally specific enough to guide contributions while avoiding
date promises before release readiness is verified.

## Current Release Line

- Publish the first stable `astro-cli-commands` plugin release after the
  repository quality, documentation, security, and release gates are verified.
- Update marketplace installation guidance to distinguish stable tags from
  `main` development tracking.
- Keep release notes tied to the plugin changelog and generated release
  evidence.

## Marketplace Foundations

- Maintain schema validation for skills, apps, MCP integrations, and interface
  assets.
- Keep plugin package README, changelog, manifest, and catalog registration in
  one reviewable change for product behavior updates.
- Preserve rollback instructions for marketplace metadata, release tags, and
  generated release artifacts.

## Planned Plugin Categories

- Framework command assistants for popular web stacks.
- Repository maintenance and quality-gate helpers.
- Documentation and operating-system templates for repeatable technical work.
- Spreadsheet and reporting workflows for structured operational analysis.
- MCP integration helpers that document permissions, side effects, and recovery
  behavior clearly.

## Public Documentation

- Keep the repository README as the public homepage while the repository
  remains a lightweight marketplace and data source rather than a web
  application.
- Keep installation, contribution, validation, release, and rollback guidance
  in versioned repository documentation.
- Add examples only when they can be validated against real plugin packages.

## Contribution Maturity

- Expand contributor guidance as new plugin surfaces are added.
- Keep GitHub issue forms and pull-request templates aligned with validators.
- Require validation evidence in pull requests before marketplace changes are
  reviewed for release.
